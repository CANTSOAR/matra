## Notes

- **FAST Agreement (v3.0).** The Founder Institute serves the template as a Word .docx from Google Drive, not a PDF, so it was saved as .docx. It is a short advisor agreement covering services, compensation, an expense pre-approval rule, termination on 5 days' notice, independent-contractor status, confidentiality, IP assignment ("work made for hire"), the company's right to publicize the advisor's name, and a no-conflicts clause. The equity terms are **non-qualified stock options vesting monthly over 2 years with a 3-month cliff, 100% acceleration on sale**. Schedule A sets three tiers, each with an expected 5-10 hours per month: **Standard** (0.50% / 0.25% / 0.10% at pre-seed / seed / Series A), **Strategic** (0.75% / 0.50% / 0.25%) and **Expert** (1.00% / 0.75% / 0.50%). The tiers also spell out meeting cadence, responsiveness, promotion, recruiting and introductions.
- **University charters.** These are clean, real-world examples of the "advisory only" structure. Cornell's charter states that "All Council recommendations are advisory to the Department Chair for implementation at his/her discretion." Both charters cover purpose, membership, terms, chair, meetings and expectations. For this product, add the following sections, which these charters lack: confidentiality; conflicts of interest (especially for university faculty); **no access to survivor data**; no attorney-client relationship or legal advice to users; public-listing consent; and the protocol-review scope.
- **Not obtained.** No free downloadable advisory-board charter template was found from BoardSource or the National Council of Nonprofits. BoardSource sells its templates, and councilofnonprofits.org returned HTTP 403 to automated fetch. Their advisory-council guidance page (https://www.councilofnonprofits.org/running-nonprofit/governance-leadership/advisory-councils) can be read in a browser. Search results for "advisory board charter template" were dominated by spam/SEO template sites, which were deliberately skipped.

## README discrepancies (README.md sections 2 and 5)

1. **FAST is an equity agreement for for-profit companies.** README line 100 suggests using FAST "adapted for non-profit/civic tech". FAST v3.0 is built around **stock options** in a corporation with a board. A 501(c)(3) has no equity, so for a nonprofit you would strip the compensation, option and vesting terms and keep only the services, confidentiality, IP, termination and conflicts clauses. That turns it into a volunteer advisor agreement plus the charter (now drafted as `docs/legal/advisor-agreement.md`). A PBC with advisor equity is not an option for Matra: a for-profit entity can't run attorney routing in NJ (Legal Memo §5).
2. **Vesting differs from the README.** README line 108 says "0.1%-0.5% equity vesting quarterly over 1-2 years". FAST v3.0 uses **monthly** vesting over **2 years** with a **3-month cliff** and full acceleration on sale. FAST's Schedule A ranges are **0.10%-1.00%** depending on tier and stage, so the README's 0.1%-0.5% range only covers the Standard tier. The Schedule A duties are also sales and recruiting oriented ("make introductions", "acquisition of marquee customers"), which do not fit a clinical or legal review council.
3. **Name of the template.** README calls it the "Free Advisor Agreement (FAST)". The official name is **Founder/Advisor Standard Template (FAST)**.
4. **Coalition choice.** README line 71 names only NJCEDV (domestic violence). For a sexual-assault intake product, **NJCASA** (NJ Coalition Against Sexual Assault, representing the county rape crisis centers) is the more directly relevant statewide coalition, and the README should add it.
5. **Rutgers clinic naming.** README refers generically to "Domestic Violence, Women's Rights" clinics. These exist as the Rutgers **Domestic Violence Clinic (Camden)** and the **RBG Women's Rights and Gender Justice Clinic (Newark)**. NYU Law has no dedicated DV or sexual-assault clinic; its Technology Law & Policy Clinic is the better fit there.
6. **Public association clause.** FAST already grants the company the right to use the advisor's name and image *during the term* (clause "Company's Right to Disclose"). README line 111 wants listing **only after** the advisor has reviewed and approved the protocol, so FAST must be amended for that. Note that FAST's preamble says the parties have not modified the form, so any modification should also remove or adjust that sentence.
